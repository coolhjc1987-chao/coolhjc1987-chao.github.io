# 游戏源码

两个游戏的源码与可直接打开的单文件版。

- `wudao-xiaying/` —— 《雾岛侠影》武侠奇幻两人卡牌游戏
  - `game.html`：单文件完整版（代码、角色图片、全部 33 个音效/音乐均已内嵌，直接用浏览器打开即可玩，含局域网双机对战）
  - `source/index.html`：游戏源码（原版，需配合 `assets/` 下的图片与音频文件使用）
  - 原跳转页 `wudao-xiaying/index.html`（仓库根目录下同名目录）未动，仍跳转到 Muse 分享链接。
- `youqi-hunzhan/` —— 《3D 油漆混战》3D 跑酷油漆对战游戏
  - `index.html` + `assets/three.min.js`：完整源码，直接打开 `index.html` 即可玩
  - `game.html`：单文件版（three.js 已内嵌）

公开仓库，任何人可见。
